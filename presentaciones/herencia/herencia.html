1. Los 3 Puntos Clave

1. Clase Padre e Hija

Padre (Base): Contiene atributos y métodos generales.


Hija (Derivada): Hereda todo del padre y añade o modifica sus propias funcionalidades.

2. Sintaxis y super()

Sintaxis de herencia:

class Hija(Padre):


super().__init__() llama al constructor de la clase padre para reocupar su lógica sin duplicar código.

3. Sobrescritura (Overriding)

Permite a la clase hija redefinir un método con el mismo nombre que la clase padre.


Cambia el comportamiento por defecto adaptándolo a las necesidades específicas del hijo.

2. Ejemplo Completo

# Clase Padre (Base)
class Vehiculo:
    def __init__(self, marca):
        self.marca = marca

    def encender(self):
        return f"El vehículo {self.marca} está encendido."

# Clase Hija (Derivada)
class Coche(Vehiculo):
    def __init__(self, marca, modelo):
        super().__init__(marca) # Hereda el atributo marca
        self.modelo = modelo

    # Sobrescritura del método encender()
    def encender(self):
        return f"El coche {self.marca} {self.modelo} ruge al encender."

# Uso
auto = Coche("Ford", "Mustang")
print(auto.encender())
